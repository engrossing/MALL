# 거래처 전용몰 (벤더/유통사 폐쇄몰)

승인된 거래처만 로그인해서 상품을 볼 수 있는 회원제 폐쇄몰입니다.

## 주요 기능

- 거래처 회원가입 + 관리자 승인제 로그인
- 거래처 등급별 차등 단가 (등급 기본 할인율 + 상품별 개별 지정가)
- 상품/재고 관리 (관리자), 상품 이미지 업로드 (Vercel Blob 저장소 연결 시)
- 견적요청 / 발주요청 및 관리자 승인·확정 처리
- 결제는 계좌이체 안내 방식 (온라인 결제 연동 없음), 세금계산서 요청 표시

## 배포 방법 (코딩 지식 불필요)

이 프로젝트를 실제로 인터넷에서 운영하는 방법은 별도로 안내해 드린
"배포 가이드" 문서를 순서대로 따라 하시면 됩니다. (GitHub 업로드 → Vercel 연결 →
데이터베이스 연결 → 완료, 총 4단계)

## 기본 관리자 계정

배포 시 환경변수로 지정한 `SEED_ADMIN_EMAIL` / `SEED_ADMIN_PASSWORD` 값으로
관리자 계정이 자동 생성됩니다. 반드시 배포 전에 이 값을 원하시는 이메일/비밀번호로
바꿔서 등록해주세요.

## 사용 흐름

1. 거래처가 `/signup`에서 가입 신청
2. 관리자가 `/admin/users`에서 승인 (이때 거래처 등급 지정 가능)
3. 관리자가 `/admin/products`에서 상품/재고 등록
4. 관리자가 `/admin/tiers`에서 등급별 할인율 또는 상품별 개별 단가 설정
5. 승인된 거래처가 `/mall`에서 상품을 담아 견적/발주 요청
6. 관리자가 `/admin/orders`에서 확인 후 확정(계좌 안내) 또는 거절
7. 거래처가 `/mall/orders`에서 처리 현황과 입금 계좌를 확인

## (개발자용) 로컬 실행 방법

로컬 컴퓨터에 Node.js와 PostgreSQL이 설치되어 있다면 아래처럼 실행할 수 있습니다.
일반적으로는 필요하지 않으며, 배포 가이드만 따라 하셔도 됩니다.

```bash
cp .env.example .env   # 값을 채워주세요
npm install
npm run db:migrate     # 테이블 생성
npm run db:seed        # 관리자 계정 및 기본 등급/샘플 상품 생성
npm run dev            # http://localhost:3000
```

## 엑셀로 상품 일괄 등록

관리자 화면(`/admin/products`)에서 엑셀 파일(.xlsx)을 올리면 여러 상품을 한 번에
등록/업데이트할 수 있습니다. 파일에는 '상품명', '모델명', '공급가'로 시작하는
열이 반드시 있어야 하며, '제조원', '입수량', '제품구성', '원산지', '상품설명',
'대표이미지' 열이 있으면 함께 반영됩니다. '모델명'을 상품코드(SKU)로 사용하므로,
이미 등록된 모델명으로 다시 업로드하면 새로 만들어지지 않고 내용만 갱신됩니다.
'대표이미지' 열의 URL은 그대로 저장되어 별도의 이미지 저장소 연결 없이도
바로 사용할 수 있습니다. 단, 재고 수량은 파일에 없으므로 0으로 등록되니
업로드 후 실제 재고를 입력해주세요.

## 상품 이미지 업로드

상품 등록/수정 화면에서 이미지를 올리려면 Vercel 프로젝트의 **Storage** 탭에서
**Blob** 저장소를 하나 추가해야 합니다 (데이터베이스를 Neon으로 연결했던 것과
같은 방식입니다). 연결하면 `BLOB_READ_WRITE_TOKEN` 환경변수가 자동으로
추가됩니다. 연결 전에 이미지를 올리면 상품 정보는 정상 저장되고 이미지만
건너뛰며, 화면에 안내 문구가 표시됩니다.
